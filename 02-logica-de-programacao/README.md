## Pontos de Atenção / Correções
- **Filas e Pilhas em Python (`append`/`pop` vs. `enqueue`/`push`):** `push()` e `enqueue()` são nomes conceituais; em listas do Python usa-se `.append()` e `.pop()`.
- **Operador Diferente (`!=`):** A página 19 da apostila tem um erro de digitação (`"=!"` no texto), mas o operador correto em Python é `!=`.
- **Constantes em Python:** Python não trava constantes na memória; usa-se letras `MAIUSCULAS` por convenção (PEP 8).
- **PEMDAS:** Multiplicação e Divisão têm a mesma precedência (executam da esquerda para a direita), assim como Adição e Subtração.
